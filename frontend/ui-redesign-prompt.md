# Swiss Web Design UI Redesign Prompt

**Context:** The current UI is too cluttered, overly colorful ("vibe-coded"), and lacks structural elegance. 

**Role:** Act as a world-class UI/UX designer and frontend engineer specializing in modern **Swiss Web Design** (International Typographic Style adapted for digital, interactive experiences).

**Task:** Redesign the `@frontend` to be strictly minimalistic, highly functional, yet **interestingly beautiful**. Strip away the noise and rebuild the aesthetic based on the following constraints:

1. **Interestingly Beautiful (The "Wow" Factor):**
   - Minimalism shouldn't mean boring. Create visual intrigue through extreme, bold contrasts in scale and weight.
   - Incorporate purposeful, fluid micro-interactions and smooth state transitions. Motion should feel deliberate, crisp, and premium—never bouncy or overly playful.
   - Utilize asymmetrical but perfectly balanced grid layouts that feel highly editorial and sophisticated.

2. **Typography as the Hero:** 
   - Use a clean, highly legible sans-serif font (e.g., Inter, Helvetica Neue, or system-ui).
   - Establish a stark, mathematical typographic hierarchy. Use oversized, striking typography for key headings to create art out of text.
   - Favor left-aligned text; avoid center alignment for long copy.

3. **Restricted, High-Contrast Color Palette:** 
   - Strip away excessive colors and gradients. 
   - Use a stark, high-contrast monochrome base (deep blacks, crisp whites, and deliberate shades of gray).
   - Use a maximum of *one* single vibrant accent color sparingly, only for primary actions or critical states, letting the content and typography do the heavy lifting.

4. **Strict Grid & Massive Whitespace:** 
   - Implement a rigorous, underlying geometric grid. 
   - Use generous, intentional whitespace (negative space) to frame elements. Let the layout breathe. Do not rely on borders or bounding boxes to separate content; let the grid and spacing do the work.

5. **Crisp UI Elements:** 
   - Remove all unnecessary decorative elements (no heavy drop shadows, no glassmorphism, no excessive borders).
   - Keep UI components flat, crisp, and purposeful. Use sharp edges or very subtle, tight border radii.

**Execution:** Review the current components in `@frontend` and apply these principles. Ensure the code implementation is as elegant, performant, and clean as the design itself.
